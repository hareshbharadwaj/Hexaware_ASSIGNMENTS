# Day 9 – Views, Stored Procedures, Functions and Cursors

**Database:** MySQL 8.4 LTS

This folder contains solutions for all three assignment sets:
1. Retail Order Fulfilment
2. Insurance Premium Processing
3. Telecom Low-Balance Follow-up

Each set contains a schema/setup script, views, procedures/functions, cursor and set-based alternatives, and a comparison note.

## Run order
For each set, open a MySQL 8.4 session and run `schema.sql`, then `views.sql`, `procedures.sql`, and finally `cursor.sql`. Cursor and set-based statements are alternatives; reset the log/notification tables before comparing them to avoid duplicate rows.

The accompanying PDF solution is named `Day_09_Complete_Solutions.pdf` in the assignment pack. SQL scripts are examples using the schemas in this folder; adapt names if using an existing database.

**Note:** Scripts are supplied for MySQL 8.4. They have not been executed against a live MySQL server in this session. Timing comparisons must be measured in the user's own environment; no execution times are claimed.
