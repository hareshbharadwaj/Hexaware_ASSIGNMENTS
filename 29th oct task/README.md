## Run a Java file

Compile and run an individual source file from this folder, for example:

```bash
javac Set1_Task1_OrderSearch.java
java Set1_Task1_OrderSearch
```

The examples are standalone demonstrations. Timing results vary by machine; use the full CSV input where the assignment asks for it. Review each task's comments and extend the sample data as needed for the full assignment requirements.
