## Run a Java file

Compile and run any individual source file from this folder, for example:

```bash
javac Set1_Task1_OrderSearch.java
java Set1_Task1_OrderSearch
```

Some examples use Java records and require Java 16 or newer. The PDF's console images are illustrative sample outputs; run the programs locally to verify output and measure machine-dependent timings.
